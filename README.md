# _**blue-noise.js**_
### Free, generic JavaScript implementations of blue-noise algorithms and related sampling methods.

Overhauled to be more generic and serve as a reference for porting to other programming languages. \
Implemented in plain JavaScript with no external dependencies.

Currently implemented:
 - Void and Cluster (Ulichney 1993)
 - Blue-noise Dithered Sampling (Iliyan 2016)
 - Direct Binary Search (Allebach 1996)
 - Mitchell's Best Candidate (Mitchell 1991)
 - Lloyd Relaxation
 - Gaussian Blue Noise (Ahmed 2022)
 - General Spectrum Noise (Li-Yi Wei 2012)
 - Voronoi Diagram
 - Delaunay Triangulation (Bowyer Watson)
 - Differential Domain Analysis (Li-Yi Wei 2011)
